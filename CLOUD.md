## Работа

Telegram передаёт подписанный `initData`; сервер проверяет Ed25519-подпись
официальным production-ключом Telegram, ID бота, возраст до часа и ID владельца.
Сырые `initData` не сохраняются в таблицах или логах. Нет входа по имени пользователя.
Через час приложение нужно переоткрыть. Токен бота облаку не нужен.

В закрытых таблицах Supabase находятся задания и ответы (объявления,
характеристики, ИИ-разборы, личные фильтры и статусы). Эти данные не доступны
`anon`/`authenticated`: включён RLS без разрешающих политик, grants отозваны.
Edge Function использует штатный server-only service role. Задания старше суток
удаляются при следующем опросе работающим мостом. Ключ моста хранится локально
в игнорируемом `runtime/cloud-bridge.json`; в базе хранится только SHA-256.

Мост делает только исходящие HTTPS-запросы. Он исполняет разрешённые операции
объявлений через локальный сервер. Пути OAuth, произвольные URL и файлы запрещены.
Сеанс локального приложения, CSRF и email аккаунта не передаются в Mini App.
Учётные данные ChatGPT остаются в защищённом локальном хранилище Windows.

Оригинальные фотографии Mini App загружает непосредственно с сайтов объявлений.
Веб-сайты с фотографиями получают обычный запрос изображения с устройства пользователя.

## Обновления и ограничения

`start.cmd` запускает локальное приложение, бот и настроенный мост.
`start-bridge.ps1` / `stop-bridge.ps1` управляют мостом отдельно.
Новые объявления обновляются сборщиком с интервалом из `config.toml` (900 секунд).
Открытый Mini App запрашивает список и текущую карточку раз в минуту и при возврате
в Telegram. Текущие фильтры, сортировка и число видимых карточек сохраняются.
Исходный порядок — цена по возрастанию, 10 объектов и «Ещё 10».

Компьютер должен работать. HTTPS-хостинг и Supabase не заменяют локальный сборщик
и ChatGPT. Когда компьютер выключен, новые запросы не выполняются; приложение
покажет недоступность сборщика. Сквозной запуск требует доступа компьютера к Supabase.
Уже отправленные Telegram-сообщения не переписываются автоматически; обновляются
данные Mini App, а разделы обычной карточки редактируются кнопками.

Изменения кода проверяются GitHub Actions при push. Размещение новой версии Sites
выполняется штатным Sites workflow, а не автоматически из публичного репозитория.
Ключи хостинга не коммитятся. Edge Function публикуется отдельно с проверкой auth.

## Проверки и сборка

```powershell
.venv\Scripts\python.exe -m unittest discover -s tests
node --test tests/telegram-auth.test.mjs
.venv\Scripts\python.exe miniapp/build.py
node --check miniapp/dist/ui.js
node --check miniapp/dist/telegram.js
```

`miniapp/build.py` собирает ровно пять публичных файлов в `miniapp/dist`.
Настройки среды, SQLite, фотографии, модели и токены туда не копируются.
Штатная SQL-схема сохранена в `supabase/radar-schema.sql`.

Для нового окружения создайте собственный случайный ключ моста и храните только
его хеш в `radar_bridge_config` вместе с ID бота и разрешённого Telegram-владельца.
Не переносите локальную сессию ChatGPT в облако. Для восстановления подключения
запустите `open-app.cmd` на компьютере владельца.
