# Радар объявлений — локальный прототип Telegram-бота

Регион: Ростов-на-Дону и Ростовская область. Пользователь выбирает категорию кнопкой и сразу получает карточки: оригинальное фото, название, цена, местоположение и кнопка исходного сайта. В карточке показан точный рассчитанный процент разницы с аналогами, когда данных достаточно. Доступны фильтры 10%+, 20%+, 30%+ и просмотр всех объявлений. Исходный жёсткий порог 40% отменён. Выбор категории и фильтра сохраняется отдельно для каждого личного чата.

**Подключён публичный HTML-каталог Авито.** Обычные запросы с этого компьютера вернули реальные карточки всех шести категорий. Бот читает до трёх видимых страниц активной категории не чаще раза в 15 минут, следует только публичной кнопке следующей страницы. При ограничении доступа делает паузу и показывает ошибку в `/status`. Нет прокси, обхода CAPTCHA, авторизации в Авито и скрытых API. Это частичный и зависимый от разметки источник, не полный поток новых объявлений и не гарантия стабильности. Импорт JSONL остаётся альтернативой.

## Несколько источников и автосводки

Подключены публичные каталоги **Авито, Яндекс Недвижимости и Дрома**. Дополнительные источники загружают одну видимую страницу не чаще раза в 15 минут. Яндекс — пять категорий недвижимости в Ростове и ближайших населённых пунктах, Дром — автомобили Ростова-на-Дону. Авито — шесть категорий области. Циан не подключён: обычный запрос не дал пригодных видимых карточек. Каталоги могут ограничивать доступ и менять разметку; `/status` показывает состояние каждого источника. Проценты рассчитаны по доступной части рынка. Для карточек второго источника без необходимых характеристик оценка не присваивается.

Внизу Telegram — четыре кнопки: категории, сводка, настройки сводок, источники. `/summary` собирает **до 20 объектов** отдельными постами с индивидуальными кнопками. У каждого фото есть цена, адрес, сравнение и прямая ссылка. Если фото недоступно, остаётся текстовая карточка. Если подходящих объектов меньше 20, повторов для заполнения нет. Повторяющиеся выпуски могут включать ранее показанные объявления, это явно указано.

`/settings` — несколько категорий для сводки, независимо от ручного просмотра, и расписание по Москве (UTC+3):
- 12 раз — 00:00, 02:00, …, 22:00, включая ночь;
- два раза — 09:00 и 19:00;
- один раз — 09:00;
- выключить автосводки. `/stop` выключает всю автоматическую доставку.

Слоты сохраняются в SQLite до отправки: после перезапуска тот же выпуск не запускается повторно. При сетевом сбое выпуск помечается как незавершённый в `/status`, автоматический повтор не делается, чтобы не дублировать уже доставленную часть. Окно отправки — первые 30 минут слота; пропущенные за время выключения ПК выпуски не копятся. Компьютер и процесс бота должны работать; облачного размещения и запуска при входе Windows пока нет. Таймер встроен в приложение, отдельная автоматизация Codex не нужна.

Повторы одинаковой ссылки и строгие совпадения длинного описания, адреса, площади и категории не увеличивают выдачу и число аналогов. Изменённые тексты перепубликаций автоматически распознаются не всегда.

## Быстрый запуск на Windows

Python 3.11+; разработка проверяется на установленном Python 3.13. Для официального входа ChatGPT используются PyJWT и cryptography. Установка: `.venv\Scripts\python.exe -m pip install -e .`.

```powershell
cd C:\Users\big-a\Documents\Codex_bisness\garage-radar
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m garage_radar demo
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

`demo` работает без сети, токенов, модели и рабочей базы. Все объявления в демонстрации вымышлены и помечены; ориентир из демонстрации не является оценкой реального рынка Ростова.

## Telegram

1. Создать бота через официальный [BotFather](https://t.me/BotFather), получить токен.
2. Скопировать `.env.example` в `.env`, заполнить `TELEGRAM_BOT_TOKEN` и числовые ID разрешённых личных чатов в `TELEGRAM_ALLOWED_CHAT_IDS`. Токен не отправлять в переписку и не сохранять в Git. Приложение не вызывает сторонних ботов для получения ID.
3. В `config.toml` выбран `source.provider="public_catalogs"`. Для файлового импорта можно переключить на `file`.
4. Запустить `.\.venv\Scripts\python.exe -m garage_radar bot` и отправить своему боту `/start`.

Команды: `/category` — меню категорий; `/filters` — выбранные параметры; `/digest` — выдача по три карточки; `/recent` — последние загруженные карточки (порядок не гарантирует новизну публикации); `/check ID` — расчёт; `/history ID` — наблюдавшиеся цены; `/ai ID` — локальная ИИ-сводка; `/demo` — вымышленный пример; `/status` — состояние; `/stop` — отключить уведомления. В карточках есть кнопки объявления, расчёта и ИИ-сводки.

При настройке на этом компьютере создана одноразовая привязка владельца по приватной start-ссылке; идентификатор первого подтвердившего код личного чата сохраняется в SQLite. Другой пользователь не сможет занять место уже привязанного владельца. Реальный токен хранится только в игнорируемом `.env`. Локальный `.env` проекта имеет приоритет над переменными других приложений. Перед стартом сверяется ID бота из токена с `getMe`.

`start.cmd` / `start-all.ps1` запускают локальный ИИ и бота. `start-bot.ps1` запускает бот скрытым фоновым процессом, `stop-bot.ps1` останавливает только процесс, чей PID и время создания совпадают с записью проекта. `start-ai.ps1` запускает локальную Ollama. Облачный сервер не настроен; компьютер должен быть включён и подключён к интернету. Проверка настройки автозапуска фиксируется отдельно в `logs/deployment.json`, если он создан при установке.

Можно выбрать категорию без кнопок: `/category apartment`, `/category garage`, `/category house`, `/category land`, `/category car`, `/category commercial`. Активна одна категория на пользователя. Проценты выбираются кнопками; «Все объявления» открывает выдачу без фильтра оценки, «Ещё объявления» продолжает просмотр. Регион, число аналогов и интервал пока задаются в `config.toml`. Уведомления по умолчанию начинаются с 10%, пользовательский выбор 20% или 30% меняет и их порог.

Фоновый просмотр базы идёт по `poll_seconds`, источник обновляется отдельно с интервалом `source.refresh_seconds`. Точный интервал зависит также от long polling Telegram, сети и времени ответа ИИ. Новому подписчику отправляются подходящие актуальные кандидаты; повтор по той же цене подавляется, изменение цены может дать новое уведомление. После неоднозначного сетевого сбоя возможен повтор. Не запускать два процесса бота с одним токеном. ПК и процесс должны работать для уведомлений; сервер не развёрнут.

## Данные и импорт

Одна JSON-запись на строку UTF-8. Поля ниже обязательны, кроме указанных defaults. `observed_at` — время, когда источник действительно наблюдал запись, с часовым поясом; переписывание даты старой записи делает оценку недостоверной. `active=false` — явное снятие. Отсутствие строки в очередном файле само по себе не снимает объявление. Данные старше `max_age_days` не участвуют.

```json
{
  "id": "avito-REAL_ID",
  "url": "https://www.avito.ru/REAL_LISTING_PATH",
  "title": "Заголовок из источника",
  "description": "Текст из источника",
  "region": "Ростовская область",
  "locality": "Ростов-на-Дону",
  "district": "Советский",
  "price_rub": 600000,
  "area_m2": 24,
  "garage_type": "capital",
  "ownership": "owned",
  "land_rights": "owned",
  "condition": "normal",
  "observed_at": "2026-10-20T12:00:00+00:00",
  "category": "garage",
  "attributes": {},
  "transaction": "sale",
  "price_basis": "total",
  "active": true,
  "demo": false
}
```

Это описание формата, не реальное объявление. В JSONL каждый объект должен быть на одной строке. Подставить факты и дату наблюдения из источника. Не заполнять неизвестные права как `owned`: использовать `unknown`, при котором уверенная оценка будет недоступна.

```powershell
.\.venv\Scripts\python.exe -m garage_radar import C:\path\to\listings.jsonl
.\.venv\Scripts\python.exe -m garage_radar digest
```

Для повторного файлового импорта указать `runtime.feed_file` в `config.toml`. Поставщик должен заменять файл атомарно после записи целиком. Весь файл проверяется до записи, изменения импортируются одной транзакцией. Старые версии записи не затирают новые; цена и время наблюдения сохраняются в истории. Произвольная ссылка, отправленная в чат, автоматически не загружается: публичный адаптер читает настроенные категории.

Общие значения: `ownership`: `owned`, `membership`, `share`, `unknown`; `land_rights`: `owned`, `lease`, `unknown`; `condition`: `normal`, `needs_repair`, `unknown`; `garage_type`: `capital`, `metal`, `parking`, `unknown`. Для категорий кроме гаражей ставить `garage_type=unknown`. Все цены в рублях. `transaction=rent` и `price_basis=per_m2|deposit|auction_start` исключаются из расчёта продажи целого объекта.

## Сравнение по категориям

Для полной модели совпадают населённый пункт, группа местоположения, категория, состояние и право на целый объект. Неизвестные важные характеристики блокируют полный расчёт. У автомобилей `area_m2=null`; для остальных площадь в м², включая землю.

Публичные карточки часто не содержат документов и состояния. Для них допускается только **предварительное сравнение**, а не подтверждённая выгода. Тип дома, коммуникации и часть других факторов могут быть недоступны; отсутствующие факторы перечисляются в подробном расчёте. Ключевые признаки категории и минимум аналогов всё равно требуются. Сначала подбираются аналоги из той же группы местоположения. Если их мало, для публичных данных допускается сравнение с похожими объектами того же города, с явной надписью «по городу, без поправки на район». Ростов и Батайск не смешиваются. Это не оценка реальной стоимости сделки и не автоматическое определение административного района по адресу.

| Категория | Дополнительные признаки `attributes` и правила |
|---|---|
| Гаражи | Одинаковый `garage_type` и статус земли; площадь ±20% |
| Квартиры | `rooms`, `building_type`, `market_segment`, `floor_group`; площадь ±20% |
| Дома | `wall_material`, `utilities`, `house_use`; одинаковые права на землю; площадь дома и числовая `land_area_m2` ±20% |
| Участки | `land_use`, `utilities`, `access`; одинаковые права на землю; площадь ±20% |
| Автомобили | `make`, `model`, `generation`, `engine`, `gearbox`, `drive`, `accident_status`; числовой `year` ±1, числовой `mileage_km` ±25 000 км |
| Коммерческая | `property_type`, `purpose`; площадь ±20% |

Источник должен нормализовать значения признаков: `brick` и «кирпичный» автоматически синонимами не считаются. Документы, состояние, ДТП, права и технические признаки здесь являются данными источника, а не выполненной проверкой.

Для недвижимости берётся медиана цены за м² аналогов × площадь объекта; для автомобилей — медиана полной цены. Минимум пять аналогов, сам объект и повторы одной нормализованной ссылки исключаются. Слишком высокий относительный медианный разброс блокирует сигнал. Формула отклонения: `1 − цена / ориентир`. В карточке показывается рассчитанный процент; фильтры 10%, 20% и 30% включают своё граничное значение.

**Ограничения модели:** это прозрачный baseline по ценам предложения, не обученная оценочная модель и не подтверждённая цена сделки. Район может быть слишком крупным; не учтены все микролокации, состояние ремонта и индивидуальные дефекты. Перепубликации с новыми ссылками могут дублировать один объект. Словарные риски могут реагировать на отрицание («не затапливает»); их нужно уточнять. Пока нет оценки качества на реальной истории. Процент разницы не является гарантией доходности.

## ИИ-сводка

Адаптер [Ollama Chat API](https://docs.ollama.com/api/chat) обращается только к `127.0.0.1:11434`. Имя локальной модели задаётся в `OLLAMA_MODEL`. Сводка запускается кнопкой или `/ai ID`, не при каждом сканировании. Скорость и качество зависят от модели и ПК. Внешний облачный провайдер не подключён.

`setup-local-ai.py` скачивает переносимый runtime из официального репозитория Ollama с проверкой SHA256. `download-qwen.py` скачивает GGUF из официального репозитория Qwen с проверкой опубликованной LFS SHA256. Эти установочные скрипты отдельно запрашиваются при настройке; обычный бот ничего не скачивает. Все крупные файлы лежат в игнорируемом `runtime/`. При скачивании проверяется запас свободного места. Импорт модели выполняется по [официальной инструкции Ollama](https://docs.ollama.com/import).

Вход ИИ: объявление и рассчитанная карточка. Модель возвращает структурированные цитаты и три вопроса продавцу. Программа показывает цитату только если этот фрагмент действительно присутствует в тексте источника; при отсутствии оценки отдельно пишет, что скидка не установлена. ИИ не принимает решение о пороге, не выполняет инструменты и не подтверждает юридическую чистоту. При отсутствии модели базовый расчёт работает. На этом компьютере проверена реальная генерация локальной модели `business-radar` (Qwen3 4B). Первый запрос загружает модель и может занять больше минуты; повторный тест занял около двух секунд.

API Telegram реализован по [официальной документации](https://core.telegram.org/bots/api). Приложение использует long polling, меню, callback-кнопки и ограничение доступа по личным chat ID; платежей, общения с продавцами и авторизации в Авито нет.

## Даты, сортировка и следующие 20

Ручная и автоматическая выдача ограничены 7 сутками по `attributes.site_date_at`, разобранной из видимой даты сайта. Поле `observed_at` отражает только загрузку и не используется как дата публикации. Без доступной даты запись исключается. Поднятие или обновление объявления может менять дату каталога; исходная первая публикация и отсутствие снятия с продажи отдельно не подтверждены. По умолчанию сортировка «Новые», доступны «Цена ↑» и «Цена ↓»; выбор сохраняется для сводок и ручного просмотра. После порции 20 объектов — кнопка следующих 20. Снимок ID сохраняет порядок при новых загрузках; устаревшая кнопка после нового выпуска предлагает открыть свежую сводку.

## Приложение и ChatGPT

`open-app.cmd` или `start-app.ps1` открывает локальное приложение на http://127.0.0.1:8766/. Слева категории и свежие объекты; справа фото, доступные характеристики, полный полученный текст, избранное и ИИ-разбор. Интерфейс адаптируется к ширине окна. Сервер принимает соединения только с loopback; это не опубликованное Telegram Mini App. `stop-app.ps1` останавливает только собственный процесс.

Вход: «ChatGPT и настройки» → Continue with ChatGPT → авторизация и разрешение на официальной странице OpenAI. OAuth: PKCE, state, nonce, проверка подписи ID-токена по официальному JWKS, issuer, audience и разрешения на использование плана. Токены шифруются Windows DPAPI текущего пользователя в игнорируемом runtime/chatgpt/. Обновление токенов сериализовано между приложением и ботом. Выбор модели — только из каталога аккаунта. Подключение и доступность требуют настоящего входа; тесты с вымышленными токенами не подтверждают подключение аккаунта.

Разбор читает публичную полную страницу (кеш 6 часов), прикладывает до 3 исходных фотографий и запрашивает web_search для района и спроса. Данные объявлений считаются недоверенными. При ограничении сайта явно показывает ограниченный охват; если фото не загрузились, число проанализированных фото — ноль. Если поиск не разрешён аккаунту, район не считается исследованным. Модель не подтверждает техническую исправность машины или юридическую чистоту недвижимости; ставки аренды, расходы и доходность без источников не присваиваются. Источники веб-разбора показываются отдельными ссылками.

После подключения аккаунта новые Telegram-посты ставятся в очередь фонового анализа; краткий вывод дописывается к посту, полный доступен через «Анализ» и в приложении. До подключения остаётся локальная текстовая модель, которая фотографии не анализирует. Используются лимиты плана ChatGPT; результаты кешируются. Кнопка «Отключить ChatGPT» отзывает сеанс и удаляет локальные токены; если удалённый отзыв не подтверждён, приложение сообщает об этом.

## Единая карточка

Интерфейс выбранного второго варианта установлен в локальном приложении: скругление 25 px, оригинальные фотографии высотой 212 px, постоянный краткий вывод ИИ, вкладки и раскрываемый текст продавца. Запуск: `open-app.cmd`. Анализ, описание, аналоги и избранное в Telegram теперь обновляют исходный пост. Для длинных разделов используются страницы с кнопками Назад/Далее. Текст не теряется и новые сообщения при переключении разделов не отправляются. Фоновый разбор не перезаписывает открытый пользователем раздел.

Полный интерфейс работает по локальному адресу на этом компьютере. Для открытия этого интерфейса как Telegram Mini App с телефона всё ещё требуется отдельное HTTPS-размещение с проверкой авторизации Telegram; локальный сервер наружу не опубликован.

## Размер подборки

По умолчанию бот, ручная выдача и автосводка показывают до 10 свежих объектов. Кнопка Ещё 10 открывает следующую порцию. В приложении первые 10 записей раскрываются следующими десятками без сброса прокрутки. В сводке порядок закреплён снимком списка; записи, ставшие неактивными или устаревшими после первой страницы, пропускаются. Свежесть: не более 7 дней по доступной дате сайта. Это не подтверждение наличия объекта у продавца.

## Поиски и работа с объектами

Основной порядок теперь цена по возрастанию среди предложений с датой сайта до 7 дней. Режимы: все, непросмотренные, скрытые, снижение цены и этапы Интересен / Связался / Осмотр / Отказ. В карточке раздел Мои действия; скрытие обратимо. Открытие карточки отмечает просмотр. Персональные состояния и поиски хранятся в SQLite, раздельно по пользователям.

В приложении фильтры и сохранение поисков находятся под списком режимов. Можно сохранить категорию, бюджет, город или район, обязательные слова и исключения (по доступному тексту). Сохранённые поиски редактируются, копируются и удаляются. В боте: /searches, /views, /save_search Название | Город или район | Максимальная цена | Исключить слова. Категория команды берётся из текущего выбора. Выбор новой категории отключает активный сохранённый фильтр, не удаляя его.

Снижение цены определяется по наблюдениям того же объявления, не по рекламному тексту. Избранное или статус Интересен/Связался/Осмотр включает слежение автоматически, его можно выключить вручную. Поиски с включённым уведомлением следят за соответствующими предложениями, даже если другой поиск выбран в ленте. Уведомления отправляются только подписанному пользователю (/start), для свежих активных объектов, по изменениям за последние сутки, до пяти за цикл, с подтверждением доставки в базе. /stop выключает их. Без работающего компьютера мониторинга нет. Отсутствующие исходные наблюдения не восстанавливаются задним числом.
